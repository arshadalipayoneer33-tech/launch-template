FAQ

Frequently Asked Questions

Common questions regarding hosting limits, technology choices, and customization.

Is this template completely free to host and deploy?

Yes. The frontend and serverless edge functions deploy 100% free on Cloudflare Pages, Vercel Hobby, or GitHub Pages. You get automatic HTTPS and a free subdomain (e.g., yourbrand.pages.dev) without paying for hosting or a domain.

How do I rebrand this template for a new business?

Open site.config.js and update your brand name, colors, contact emails, and navigation links. The template automatically updates all pages and CSS variables without manual HTML refactoring.

Can I connect a database like Supabase or Cloudflare D1?

Yes. The starter includes pre-structured API endpoints in /functions/api/data.js and pre-wired client hooks in /public/js/app-demo.js ready for Supabase, Firebase, or Cloudflare D1 integration.
