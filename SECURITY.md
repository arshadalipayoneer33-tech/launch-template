# Security Policy

## Project status

LaunchFlow is a starter and demonstration project, not a production-ready authentication, data-storage, or payments system. Read the README's demo limitations before deploying it with real users or sensitive data.

## Reporting vulnerabilities

Please **do not disclose exploitable vulnerabilities in public issues**. Use GitHub's private vulnerability reporting feature if it is enabled for this repository (Security > Advisories > Report a vulnerability). If private reporting is unavailable, contact the maintainer privately through a contact method explicitly listed on the repository profile. Do not send secrets or personal data in an initial report.

Provide a concise description, affected component, reproducible steps, impact, and suggested mitigation if known. Please allow reasonable time for triage before public disclosure.

## Scope and support

No formal security support window or response-time guarantee is currently promised. Security fixes are handled on a best-effort basis. The demo session token and ephemeral data store are intentionally non-production features and must be replaced before handling confidential information.
